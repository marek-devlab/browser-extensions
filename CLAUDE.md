# Project rules

## Where this project lives (hard rule)

- **The only git remote is `origin` → `https://github.com/marek-devlab/browser-extensions.git`.** Every commit, push, branch, PR, tag or release goes there and nowhere else. Never add another remote, never push to a fork or a different repository, never mirror the code elsewhere.
- **Commit author email: `marek.devlab@gmail.com`** (set as repo-local `git config user.email`). Do not use any other address for authorship.
- **No information leaves this repository.** No deploys, uploads, store submissions, hosting of docs, telemetry, issue trackers, or messages to any external service unless the user explicitly names that destination in the conversation. Suggestions like "host PRIVACY.md at <domain>" are only valid if the user asked for that domain.
- Existing branding strings (`Blockaly`, `blockaly.com`, `*@blockaly.com` gecko ids) come from earlier commits in this repo; do not add new external domains or contacts on your own, and ask before changing the existing ones.
