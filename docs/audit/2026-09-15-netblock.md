## (a) Вердикт

**Сабмит возможен после закрытия трёх 🟡 (копия UI + мёртвая кнопка) и ручного смоука; 🔴-блокеров по политикам не найдено.** Всё, что заявлено в `wxt.config.ts`, `STORE.md` и `PRIVACY.md`, подтверждено кодом: ноль сети (`connect-src 'none'` в обоих манифестах, `npm run guards` чисто), правила = данные (строгий валидатор, `eval`/`new Function` в бандле отсутствуют), лог только в `storage.session` с безусловной маской креденшлов, CDP-поверхность ограничена семью командами и не читает тела, ничего не attach'ится без явного включения на вкладке. Главный риск ревью — не политика, а **эвристика**: `debugger` в baseline у разработчика-новичка с шестью другими разрешениями. Митигация — точные тексты обоснований (STORE.md) и прецеденты: одиннадцать живых листингов CWS с `debugger` в baseline, из них два — прямые функциональные аналоги (Netify, Network Overrides API; манифесты проверены по CRX, отданному update-эндпоинтом Google 2026-09-15).

Честная оценка вероятности прохождения CWS с первой попытки: **~65–75 %**; после одной апелляции с демонстрацией кода NL-режима — **~90 %**. AMO (Firefox): **~90 %** с первой (профиль как у `adblock`, уже описанный в Reviewer notes).
